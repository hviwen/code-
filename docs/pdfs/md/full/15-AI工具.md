## AI 辅助测试设计与跨端验证

**核心答案**

让 AI 生成审查清单；人工逐项跑恶意文本、协议 URL、断网/恢复与键盘焦点测试；扫描依赖并检查 CSP 报告。

**输入上下文**

最小 diff、数据来源/信任等级、消毒器配置（不可含 secrets）、CSP 摘要、Web/RN 行为清单。

**提示模板**

“审查以下补丁，按数据流标出 raw HTML、URL、权限、存储和网络恢复风险；每项给出需人工验证的测试，不要声称安全或执行外部代码。”

**人工验证**

Web 中确认不可信字符串只作为文本显示；RN 真机验证权限拒绝、网络切换和敏感日志掩码。

**失败模式**

将 CSP 当 sanitization、遗漏 SSR/深链、把用户内容带进提示词。

**面试回答角度**

将模型输出视作未经信任的建议；安全结论必须由代码审查、测试、扫描和生产观测共同支撑。

**项目表达**

将模型输出视作未经信任的建议；安全结论必须由代码审查、测试、扫描和生产观测共同支撑。

## 删除状态机

**核心答案**

删除流程至少包含 idle、confirming、submitting、success、failure。

**边界与取舍**

失败后需保留目标与可重试信息。

**常见误区**

一个 loading 布尔值足够描述所有状态。

## 终态恢复

**核心答案**

刷新后应从持久状态识别 cancelled/failed/completed，避免误判生成中。

**边界与取舍**

缺失终态需超时与人工恢复。

**常见误区**

没有流连接就一定已完成。

## AI 辅助生成 Web、RN、uni-app 表单与布局能力矩阵

**核心答案**

AI 产候选矩阵；人工核官方版本；删编造 API；实现共享业务 schema + 平台适配；真机/浏览器测试；记录差异与成本。

**输入上下文**

目标浏览器/RN/uni-app 版本、表单字段、布局断点、无障碍要求、现有组件；不含真实用户输入和生产凭证。

**提示模板**

`按 Web/RN/uni-app 列出原生校验、字段分组、自动填充、容器响应、浮层定位能力；每格给官方依据、能力探测、降级和人工验证，禁止把 Web API 名称映射为跨端同义。`

**人工验证**

Web 键盘/读屏/自动填充与提交；RN/uni-app 对应表单、safe area、键盘遮挡和布局；服务端仍重验；不接受截图代替行为。

**失败模式**

把 CSS container/anchor 直接复制到原生端、混淆单位/焦点、忽略版本、上传敏感表单、为少量字段引入多余框架。

**面试角度**

AI 管理能力清单，人负责版本、适配边界、安全、设备证据与模型成本。

**上下文**

AI 解析候选依赖；人工核 git graph/diff/callers；选择最小可逆方案；在隔离分支演练；跑目标门禁；人工批准发布。

**输入上下文**

脱敏提交列表、diff 摘要、测试/部署清单、flag 与数据迁移依赖；不提供凭证，不让 Agent push/revert。

**提示模板**

`输出提交依赖 DAG、三种回退候选、每种受影响路径、前置检查、验证和停止条件；遇到 merge/mainline、数据库或外部副作用必须标待人工决策，不执行命令。`

**人工验证**

base/head、commit、依赖与 revert 范围准确；算法拓扑结果与 git graph 一致；行为/视觉/权限验证通过；恢复演练可重复。

**失败模式**

把时间顺序当依赖、漏 merge mainline、建议 force-push、忽略配置/数据、伪造测试通过。

**面试角度**

AI 只能压缩审阅和方案枚举，生产变更必须人工审查、测试、安全检查和授权。

**上下文**

脱敏 commit/diff/部署依赖，不给凭证，不授权 push/revert。

**步骤**

候选 DAG → 人工核 graph/diff → 隔离分支演练 → 门禁 → 人工批准。

**项目表达**

AI 只能压缩审阅和方案枚举，生产变更必须人工审查、测试、安全检查和授权。

## 可验证 AI 前端工作流

**核心答案**

AI 对前端最有价值的作用是加速候选方案与定位，不是绕过工程准入。可靠流程是：**脱敏上下文 → 明确验收 → 最小 diff → 人工审查 → typecheck/测试 → 浏览器或真机验证 → 灰度与观测**。

“我按风险分层使用模型。低风险任务让轻量模型初筛；涉及权限、支付、缓存一致性和跨端差异的改动必须给出假设、最小 diff 和测试计划，并由人审。运行时浏览器上下文可提高定位准确度，但不上传生产敏感数据；最终是否合并由可复现测试和人工 review 决定。”
