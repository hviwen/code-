# 数组与哈希

- **1 Two Sum｜两数之和** 哈希表记录已见元素的下标；扫描到 value 时查询 target - value。时间 O(n)，空间 O(n)。
- **303 区域和检索-数组不可变** 思路：prefix[i+1] 保存前 i 个元素之和，区间和用两次前缀相减；时间复杂度：O(n) 预处理/O(1) 查询；空间复杂度：O(n)
- **56 合并区间** 思路：按起点排序，重叠则扩展末尾，否则开启新区间；时间复杂度：O(n log n)；空间复杂度：O(n)
- **560 和为 K 的子数组** 思路：若当前前缀为 sum，则此前 sum-k 的出现次数都是有效起点；时间复杂度：O(n)；空间复杂度：O(n)

# 双指针与滑动窗口

- **15 三数之和** 思路：排序后固定一个数，用双指针找相反数并跳过重复；时间复杂度：O(n²)；空间复杂度：O(1) 不计输出
- **16 最接近的三数之和** 思路：固定一个数后收缩左右指针，维护与 target 距离最小的和；时间复杂度：O(n²)；空间复杂度：O(1)
- **绝对差不超过限制的最长连续子数组** 思路： maxQ 递减、minQ 递增，存下标。加入右端后，若最大减最小超过 limit，右移左端并清过期下标

# 链表

- **142 环形链表 II** 思路：快慢指针相遇后，一个指针回到头部，同速前进再次相遇即入口；时间复杂度：O(n)；空间复杂度：O(1)
- **160 相交链表** 思路：两指针走完自己的链后切换到另一条链，路程相等时相遇；时间复杂度：O(m+n)；空间复杂度：O(1)
- **206 反转链表** 思路：逐节点保存 next、反转指向并推进 prev/current；时间复杂度：O(n)；空间复杂度：O(1)
- **88 合并两个有序数组** 思路：从两数组尾部比较，写入 nums1 的尾部，避免覆盖未处理数据；时间复杂度：O(m+n)；空间复杂度：O(1)

# 树与图

- **108 将有序数组转换为二叉搜索树** 思路：选择中点为根，递归构建左右区间以保持高度平衡；时间复杂度：O(n)；空间复杂度：O(log n)
- **207 课程表** 思路：统计入度，从零入度节点出队并减少后继入度，处理数等于节点数则无环；时间复杂度：O(V+E)；空间复杂度：O(V+E)
- **463 岛屿的周长** 思路：每个陆地贡献四条边，相邻上方或左方陆地各抵消两条边；时间复杂度：O(mn)；空间复杂度：O(1)
- **二叉树的最近公共祖先** 思路： 函数返回“该子树找到的 p 或 q，或已确定的 LCA”。遇到空节点/目标直接返回；左右均非空说明当前节点是 LCA，否则把非空结果向上交
- **腐烂的橘子（Rotting Oranges）** 难度： Medium 考点： 多源 BFS 与“按层代表时间”。思路： 初始所有腐烂点同时入队并统计新鲜数；每一层向四邻传播，层数即分钟。

- **91 解码方法** 思路：dp[i] 来自合法单字符 dp[i-1] 与合法双字符 dp[i-2]；时间复杂度：O(n)；空间复杂度：O(1)

# 字符串

- **131 分割回文串** 思路：从当前位置枚举回文前缀，选择后递归剩余字符串；时间复杂度：O(n·2^n)；空间复杂度：O(n)
- **409 最长回文串** 思路：所有偶数贡献完整，奇数贡献 count-1，中心最多取一个；时间复杂度：O(n)；空间复杂度：O(k)
- **43 字符串相乘** 思路：用长度 m+n 的数组累计每位乘积与进位，最后去前导零；时间复杂度：O(mn)；空间复杂度：O(m+n)
- **438 找到字符串中所有字母异位词** 思路：维护目标与窗口频次，窗口达到长度后比较并移出左字符；时间复杂度：O(n·Σ)；空间复杂度：O(Σ)
- **459 重复的子字符串** 思路：若由子串重复组成，则会出现在 (s+s) 去掉首尾后的内容中；时间复杂度：O(n²)；空间复杂度：O(n)
- **49 字母异位词分组** 思路：把排序后的字符作为 key，将原字符串加入对应桶；时间复杂度：O(n·k log k)；空间复杂度：O(nk)
- **5 最长回文子串** 思路：以每个字符和字符间隙为中心向两侧扩展，保留最长区间；时间复杂度：O(n²)；空间复杂度：O(1)
- **647 回文子串** 思路：每个字符作为奇数中心，每个相邻间隙作为偶数中心；相等就向两侧扩展并累计；时间复杂度：O(n²)；空间复杂度：O(1)
- **79 单词搜索** 思路：从每格尝试四方向匹配，访问后临时标记并恢复；时间复杂度：O(mn·4^L)；空间复杂度：O(L)
- **8 字符串转换整数 atoi** 思路：跳过前导空格、读取符号与连续数字，并按 32 位范围截断；时间复杂度：O(n)；空间复杂度：O(1)
