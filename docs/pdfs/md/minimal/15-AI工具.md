- **让 Agent 生成反例而不是复制实现** 先让 AI 输出候选矩阵；人工删除无业务意义组合；用现有 Vitest/测试工具实现最小反例；固定 seed；在真实边界补少量契约/E2E。
- **让 Agent 生成防数据丢失的结构化 fixture** 先让 Agent 枚举不变量与反例；人工删去不存在的 node/API；生成纯函数断言和拦截式集成测试；再由人执行 target tests…
