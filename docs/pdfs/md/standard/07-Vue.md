## Vue 测试中 nextTick 与 flushPromises 如何选择

**问题**

点击后发请求并更新 DOM，为什么只 `await nextTick()` 可能仍失败？

**考察意图**

Vue 调度与外部 Promise 边界。

**核心答案**

`nextTick` 等待 Vue 已排队的 DOM 更新，不知道 axios/fetch Mock 的未决 Promise；先等待外部 Promise（如 `flushPromises`），再在需要时等待 Vue 更新。`trigger`/`setValue` 可 await 其返回的 nextTick；async setup 按真实用法置于 Suspense。

**边界与取舍**

`flushPromises` 不是任意后台任务完成证明；仍需控制请求和断言用户可见状态。

**常见误区**

循环 nextTick、全局 sleep 或 shallow mount 后声称集成链正确。

**追问**

Teleport/Router 的边界如何处理？

## Composable 如何管理监听器、请求与 watcher 生命周期

**问题**

把编辑器配置抽成 composable 后，怎样避免重复监听、旧请求覆盖和卸载泄漏？

**考察意图**

Vue 资源所有权、响应式输入、取消和测试。

**核心答案**

同步创建 composable；用 `toValue`/getter 明确响应式输入；watch callback 的 cleanup 或 AbortController 取消旧请求；mounted 建 DOM 资源，unmounted 对称释放；返回 refs 与显式动作，不泄露可随意修改的内部状态。

**边界与取舍**

只在组件失活时暂停的资源还需 activated/deactivated；共享单例状态必须明确租约/引用计数，不能假装组件私有。

**常见误区**

watcher 自动取消所有异步任务；把 reactive 返回对象解构后仍天然响应。

**追问**

怎样用 fake timer 与 deferred promise 证明旧结果不会覆盖新结果？

## KeepAlive 与 Teleport 组合时如何定义可见性和资源存活

**问题**

缓存的评审页把浮层 Teleport 到 body，切换页面后浮层和轮询应怎样处理？

**考察意图**

逻辑树/DOM 树、activated/deactivated、焦点和资源清理。

**核心答案**

Teleport 不改变组件逻辑所有权；KeepAlive 切走触发 deactivated 而非卸载。把“实例存在、页面激活、浮层打开、请求进行中”分开；deactivated 关闭/隐藏浮层、恢复触发器焦点并暂停无需后台运行的资源，activated 按幂等规则恢复，unmounted 做最终清理。

**边界与取舍**

是否保留草稿取决于业务；外部代码移除 Teleport DOM 是额外边界，需锁版本做最小复现。

**常见误区**

Teleport DOM 仍在就代表组件仍激活；只写 onUnmounted 即可。

**追问**

`include/exclude/max` 淘汰缓存时测试哪些钩子序列？
