## 拖动位置如何跨 Web、RN、uni-app 安全恢复

**问题**

能否共享一份 `{x,y}` 和 pointer handler 到所有端？

**考察意图**

跨端输入、坐标系、safe area 与存储迁移。

**核心答案**

共享“最终位置在可操作区域内、可恢复、可重置”的领域不变量；Web 用 Pointer Events/viewport，RN/uni-app 用各自 responder/gesture、窗口与 safe-area API。持久化保存带 version 的归一化锚点或边缘偏移，读取时校验并按当前屏幕 clamp；平台适配器负责事件和存储。

**边界与取舍**

键盘、旋转、分屏、缩放、系统字体会改变可用区域；RN `pointerEvents` prop 与 Web CSS/PointerEvent 不是完全同义。

**常见误区**

直接复制 Web handler/API，或把设备像素和 CSS/布局单位混用。

**追问**

升级坐标 schema 时怎样迁移与回退？

> 难度 高级 · 审校 已修订 · 首次 2026-08-27 · 主体系
