## 自定义控件何时值得，怎样不破坏键盘操作？

**考察意图**

ARIA 的使用门槛。

**核心答案**

有原生控件时优先原生；必须定制时实现正确 role、可见焦点、键盘交互、状态和读屏名称，并以键盘和读屏实际测试验收。DOM 顺序应与逻辑焦点顺序一致。

**边界与取舍**

不用正 `tabindex` 修补视觉排序；复杂 listbox/combobox 的状态机成本很高，宜评估成熟组件。

**常见误区**

给 `div` 加 `onClick` 与 `tabindex=0` 就称无障碍。

**追问**

移动端只有触摸，为什么仍测键盘？——外接键盘、辅助技术与桌面复用路径仍依赖它。
