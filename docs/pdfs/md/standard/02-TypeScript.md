## TypeScript 如何写可演进的事件契约？

**考察意图**

类型边界与演进能力。

```ts
type TaskEvent =
  | { type: 'task.updated'; schemaVersion: 1; eventId: string; taskId: string; version: number; patch: { title?: string } }
  | { type: 'task.deleted'; schemaVersion: 1; eventId: string; taskId: string; version: number };

function apply(e: TaskEvent) {
  switch (e.type) { case 'task.updated': return e.patch; case 'task.deleted': return null; }
}
```

**核心答案**

判别联合让消费者穷尽处理；新增字段可选、未知 `type` 记录并安全忽略或触发升级；边界处以 Zod/JSON Schema 等运行时校验。

**常见误区**

相信 TypeScript 会验证 WebSocket JSON。

**追问**

破坏性变更？——新 topic/schemaVersion 双写、迁移后下线旧消费者。
