## Anchor Positioning 如何渐进增强评审提示与操作菜单

**问题**

如何让检查项提示/菜单跟随触发器并在边缘翻转，同时兼容不支持浏览器？

**考察意图**

CSS anchor、fallback、top layer、语义和兼容性。

**核心答案**

触发器与浮层先用 button+Popover/menu/dialog 的正确语义；支持时声明 anchor 与 `position-try-fallbacks`，不支持时用稳定的普通流/固定定位方案。测试滚动、缩放、嵌套 overflow、RTL、viewport 边缘、键盘关闭和焦点返回。

**边界与取舍**

Interop focus area 不等于全部兼容；Level 2 `anchored()` 查询仍是探索，不能进入生产基线。复杂 collision 可暂用已验证库。

**常见误区**

anchor positioning 自动处理 focus/dismiss；把 CSSWG explainer 语法直接上线。

**追问**

Popover top layer 与 anchor scope/overflow 的组合如何验证？
