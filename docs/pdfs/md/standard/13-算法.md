## 56 合并区间

**核心答案**

- 难度：进阶；考点：排序与扫描
- 思路：按起点排序，重叠则扩展末尾，否则开启新区间。
- 时间复杂度：O(n log n)；空间复杂度：O(n)
- TypeScript 参考实现：

```ts
function merge(intervals: number[][]): number[][] {
  intervals.sort((a,b) => a[0] - b[0]);
  const out: number[][] = [];
  for (const cur of intervals) {
    const last = out[out.length - 1];
    if (!last || cur[0] > last[1]) out.push([...cur]);
    else last[1] = Math.max(last[1], cur[1]);
  }
  return out;
}
```

- 可读测试：

```ts

```

## 3 无重复字符的最长子串

**核心答案**

- 难度：进阶；考点：滑动窗口
- 思路：记录字符最近位置，左边界只前进不后退。
- 时间复杂度：O(n)；空间复杂度：O(k)
- TypeScript 参考实现：

```ts
function lengthOfLongestSubstring(s: string): number {
  const last = new Map<string, number>();
  let left = 0, best = 0;
  for (let right = 0; right < s.length; right++) {
    const prev = last.get(s[right]);
    if (prev !== undefined && prev >= left) left = prev + 1;
    last.set(s[right], right);
    best = Math.max(best, right - left + 1);
  }
  return best;
}
```

- 可读测试：

```ts

console.assert(lengthOfLongestSubstring("bbbbb") === 1);
```

- 常见错误与前端迁移：左边界回退；前端输入去重窗口与活跃会话统计。

## 绝对差不超过限制的最长连续子数组

**核心答案**

- **难度/考点：** Medium；双单调队列。
- **思路：** `maxQ` 递减、`minQ` 递增，存下标。加入右端后，若最大减最小超过 limit，右移左端并清过期下标。
- **复杂度：** O(n) 时间、O(n) 空间。

```ts
function longestSubarray(nums: number[], limit: number): number {
  const maxQ: number[] = [], minQ: number[] = [];
  let left = 0, best = 0;
  for (let right = 0; right < nums.length; right++) {
    while (maxQ.length && nums[maxQ[maxQ.length - 1]] < nums[right]) maxQ.pop();
    while (minQ.length && nums[minQ[minQ.length - 1]] > nums[right]) minQ.pop();
    maxQ.push(right); minQ.push(right);
    while (nums[maxQ[0]] - nums[minQ[0]] > limit) {
      if (maxQ[0] === left) maxQ.shift(); if (minQ[0] === left) minQ.shift(); left++;
    }
    best = Math.max(best, right - left + 1);
  }
  return best;
}
```

```ts
console.assert(longestSubarray([8, 2, 4, 7], 4) === 2);
console.assert(longestSubarray([10, 1, 2, 4, 7, 2], 5) === 4);
```

- **常见错误：** 队列存值无法判断过期；只看相邻差；遗漏左端清理。
- **业务迁移：** 对 RTT、帧耗时等滑窗波动做在线检测；不能替代采样、分位数与异常剔除。

```ts
type ListNode = { val: number; next: ListNode | null };

    if (slow === fast) return true;
  }
  return false;
}
```

## 二叉树的最近公共祖先

**核心答案**

- **难度：** Medium；**考点：** 后序递归、分支返回值语义。
- **思路：** 函数返回“该子树找到的 `p` 或 `q`，或已确定的 LCA”。遇到空节点/目标直接返回；左右均非空说明当前节点是 LCA，否则把非空结果向上交。
- **复杂度：** 时间 $O(n)$，递归栈 $O(h)$，最坏 $O(n)$。

```ts
class TreeNode {
  constructor(
    public val: number,
    public left: TreeNode | null = null,
    public right: TreeNode | null = null,
  ) {}
}

function lowestCommonAncestor(
  root: TreeNode | null, p: TreeNode, q: TreeNode,
): TreeNode | null {
  if (root === null || root === p || root === q) return root;
  const left = lowestCommonAncestor(root.left, p, q);
  const right = lowestCommonAncestor(root.right, p, q);
  if (left && right) return root;
  return left ?? right;
}

const root = new TreeNode(3, new TreeNode(5), new TreeNode(1));
console.assert(lowestCommonAncestor(root, root.left!, root.right!) === root);
console.assert(lowestCommonAncestor(root, root.left!, root.left!) === root.left);
```

**常见错误：** 把节点值相等当作同一节点；忘记题目通常保证 `p`、`q` 存在；误用 BST 的值比较解法。
**前端迁移：** 组件树/权限树的向上归并可复用“子分支返回状态、父节点合并”的思维；真实 DOM 不应以递归遍历代替事件委托与可访问性语义。

## 腐烂的橘子（Rotting Oranges）

**核心答案**

**难度：** Medium　**考点：** 多源 BFS 与“按层代表时间”。

**思路：** 初始所有腐烂点同时入队并统计新鲜数；每一层向四邻传播，层数即分钟。结束后仍有新鲜点返回 -1。

```ts
function orangesRotting(grid: number[][]): number {
  const q: [number, number][] = []; let fresh = 0; let head = 0; let minutes = 0;
  for (let r = 0; r < grid.length; r) for (let c = 0; c < grid[0].length; c)
    grid[r][c] === 2 ? q.push([r, c]) : grid[r][c] === 1 && fresh++;
  const dirs = [[1,0],[-1,0],[0,1],[0,-1]];
  while (head < q.length && fresh) {
    const end = q.length;
    while (head < end) {
      const [r, c] = q[head++];
      for (const [dr, dc] of dirs) { const nr = r + dr, nc = c + dc;
        if (grid[nr]?.[nc] === 1) { grid[nr][nc] = 2; fresh--; q.push([nr, nc]); }
      }
    }
    minutes++;
  }
  return fresh ? -1 : minutes;
}
```

**复杂度：** 时间 O(mn)，空间 O(mn)。

**测试：**

```ts

console.assert(orangesRotting([[2,1,1],[0,1,1],[1,0,1]]) === -1);
```

**常见错误：** 单源逐个 BFS 导致重复扫描；每个节点递增分钟而不是每层递增；未处理一开始没有新鲜橘子。

**前端迁移：** 多终端离线队列/缓存失效的“波次”分析可借用多源传播模型；现实系统另需处理时钟、重试和幂等，不能直接套算法。

## 215 数组中的第 K 个最大元素

**核心答案**

```ts
function findKthLargest(nums: number[], k: number): number {
  const target = nums.length - k;
  let l = 0, r = nums.length - 1;
  while (l <= r) {
    const pivot = nums[r]; let p = l;
    for (let i = l; i < r; i) if (nums[i] <= pivot) [nums[i], nums[p]] = [nums[p], nums[i]], p;

    if (p === target) return nums[p];
    if (p < target) l = p + 1; else r = p - 1;
  }
  throw new Error("invalid k");
}
```

## LRU 缓存

**核心答案**

- **难度：** Medium；**考点：** `Map` O(1) 定位 + 双向链表 O(1) 提升/淘汰。
- **思路：** 最近使用节点放头部；`get` 命中后移动到头部；`put` 更新或新增，超过容量时删除尾部真实节点和 Map 索引。
- **复杂度：** `get/put` 均 O(1)，空间 O(capacity)。

```ts
class LRUCache {
  private values = new Map<number, number>();
  constructor(private capacity: number) {}

  get(key: number): number {
    const value = this.values.get(key);
    if (value === undefined) return -1;
    this.values.delete(key);
    this.values.set(key, value);
    return value;
  }

  put(key: number, value: number): void {
    if (this.values.has(key)) this.values.delete(key);
    this.values.set(key, value);
    if (this.values.size > this.capacity) {
      const oldest = this.values.keys().next().value as number;
      this.values.delete(oldest);
    }
  }
}

const cache = new LRUCache(2);
cache.put(1, 1); cache.put(2, 2); console.assert(cache.get(1) === 1);
cache.put(3, 3); console.assert(cache.get(2) === -1);
```

- **常见错误：** 将不存在的值与 `undefined` 混淆（本题值范围避免了该问题）；误以为 JS `Map` 能跨进程/跨 tab；漏删 Map 索引导致内存泄漏。
- **前端迁移：** 可作为内存图片/计算结果缓存的思路；真实数据缓存还需 TTL、失效、租户隔离、请求取消、错误状态和配额策略。

## O(1) 时间插入、删除和获取随机元素

**核心答案**

- **难度：** Medium；**考点：** `Map`、动态数组、索引修复。
- **思路：** 数组支持按下标随机取值，`Map<value,index>` 支持定位。删除时用数组末尾元素覆盖目标位置，更新其 index，再弹出末尾，避免 `splice` 搬移元素。
- **复杂度：** 平均 `insert/remove/getRandom` 均为 $O(1)$；空间 $O(n)$。

```ts
class RandomizedSet {
  private values: number[] = [];
  private index = new Map<number, number>();

  insert(value: number): boolean {
    if (this.index.has(value)) return false;
    this.index.set(value, this.values.length); this.values.push(value); return true;
  }
  remove(value: number): boolean {
    const i = this.index.get(value);
    if (i === undefined) return false;
    const last = this.values[this.values.length - 1]!;
    this.values[i] = last; this.index.set(last, i);
    this.values.pop(); this.index.delete(value); return true;
  }
  getRandom(): number {
    return this.values[Math.floor(Math.random() * this.values.length)]!;
  }
```

## 猜数字大小

**核心答案**

**难度：** Easy。**考点：** 有界单调搜索、把外部 API 视为契约。

**思路**

维护闭区间 `[left, right]`，不变量是答案始终在区间内。`guess(mid) === 0` 即命中；返回负数表示目标更小，收缩右边界，否则收缩左边界。中点写成 `left + Math.floor((right - left) / 2)`，跨语言时避免 `left + right` 溢出。

```ts
declare function guess(num: number): -1 | 0 | 1;

function guessNumber(n: number): number {
  let left = 1, right = n;
  while (left <= right) {
    const mid = left + Math.floor((right - left) / 2);
    const result = guess(mid);
    if (result === 0) return mid;
    if (result < 0) right = mid - 1;
    else left = mid + 1;
  }
  throw new Error('题目契约被破坏：目标不在 [1, n]');
}
```

**复杂度：** 时间 `O(log n)`；额外空间 `O(1)`。

**测试**

```ts

// 注入 makeGuess(6) 后：guessNumber(10) === 6
// 注入 makeGuess(1) 后：guessNumber(1) === 1
```

**常见错误：** 把返回符号理解反；`left < right` 但没有保证最后一项被检查；题目保证存在答案时仍静默返回 `-1`。**前端迁移：** feature flag 灰度阈值、按版本找最后一个兼容配置前，先定义单调性与边界。

## LC-733｜Flood Fill

**核心答案**

- **难度：** Easy；**考点：** 网格 DFS/BFS、边界与访问标记。
- **思路：** 保存起点旧色。若新旧色相同立即返回，否则从起点扩展四邻格；将首次访问的旧色直接染成新色，既是结果也是 visited 标记。
- **复杂度：** 时间 $O(mn)$，空间 $O(mn)$（最坏递归/队列）。深网格用迭代队列避免 JS 调用栈溢出。

```ts
function floodFill(image: number[][], sr: number, sc: number, color: number): number[][] {
  const old = image[sr][sc];
  if (old === color) return image;
  const q: [number, number][] = [[sr, sc]];
  image[sr][sc] = color;
  for (let head = 0; head < q.length; head++) {
    const [r, c] = q[head];
    for (const [dr, dc] of [[1, 0], [-1, 0], [0, 1], [0, -1]]) {
      const nr = r + dr, nc = c + dc;
      if (nr >= 0 && nr < image.length && nc >= 0 && nc < image[0].length && image[nr][nc] === old) {
        image[nr][nc] = color;
        q.push([nr, nc]);
      }
    }
  }
  return image;
}
```

**测试：**

```ts

console.assert(JSON.stringify(floodFill([[0,0,0],[0,0,0]], 0, 0, 0)) === JSON.stringify([[0,0,0],[0,0,0]]));
```

- **常见错误：** 未先处理同色导致无限入队；越界；只染一层邻居。
- **前端迁移：** 图片标注/白板选区的连通区域、表格批量选择；真实场景还要考虑大数据分帧、撤销栈与权限。

## 最近的请求次数

**核心答案**

- **难度/考点：** Easy；单调时间流、FIFO。
- **思路：** `ping(t)` 入队，移除 `< t - 3000`，队列长度即 `[t - 3000,t]` 中计数。`t` 递增。
- **复杂度：** 每元素仅进出一次，摊还 O(1)，空间 O(n)；高频场景用 head 下标而非 `shift()`。

```ts
class RecentCounter {
  private times: number[] = []; private head = 0;
  ping(t: number): number {
    this.times.push(t);
    while (this.times[this.head] < t - 3000) this.head++;
    return this.times.length - this.head;
  }
}
```

```ts
const c = new RecentCounter();
console.assert(c.ping(1) === 1 && c.ping(100) === 2);
console.assert(c.ping(3001) === 3 && c.ping(3002) === 3);
```

- **常见错误：** 写成 `<= t - 3000`；误以为 `shift()` 恒定 O(1)。
- **业务迁移：** 最近窗口埋点/速率看板；真实限流必须在服务端执行。
