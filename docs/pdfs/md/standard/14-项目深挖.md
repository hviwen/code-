## 编辑器文档评审扩展的模块边界

**问题**

如何让同一评审能力复用在多个入口，而不出现重复 payload、权限和状态逻辑？

/Users/ext.panhuiwen1/hankins/repo/uniops-ui 当前新增 document-review 扩展，并把 PRD/DRD 评审入口同时接入 slash command、insert menu 和编辑器 extension 列表；TRD 审查页增加安全与技术风险卡片。

**核心答案**

- 模块边界：扩展拥有 schema/view/payload；编辑器配置只负责注册与注入用户上下文。
- 状态：以文档节点 attrs 为可持久化状态，临时 UI 状态留在组件；避免菜单各自维护副本。
- 鉴权与安全：服务端最终鉴权；客户端禁用仅改善体验；用户信息转换在可信边界完成。
- 异常：payload 构建、插入、保存和远端评审分别处理错误，不能 void 后完全丢失。
- 测试：payload 纯函数、两个入口等价、节点序列化、只读模式、失败重试。

**追问**

为什么客户端 disabled 不能替代后端鉴权？如何处理异步 payload 构建时用户切换文档？

**关键取舍与风险**

复用 slash item 的 action 最短，但它的 range/selection 契约若是入口特定，直接适配可能埋下行为差异；应验证菜单点击时 selection 与编辑器焦点。

**落地改进**

为 buildDefaultDocumentReviewPayload 留一组纯函数测试；为 slash/insert 两个入口做等价性测试；补错误反馈和权限契约；确认样式只加载一次。

## pnpm 7 到 10 迁移与发布隔离

**问题**

你如何把一次大版本包管理器迁移拆成可验证、可回滚的工程变更？

本地 /Users/ext.panhuiwen1/hankins/uniops-ui 将 packageManager 从 pnpm 7.33.7 改到 10.25.0，lockfile 5.4→9.0，产生约 1.36 万行 diff；另一个 checkout 的构建调整也修改了 927 行 lockfile。

**核心答案**

1. 需求：先确认是工具版本治理，不顺带升级依赖。
2. 边界：manifest、workspace 配置、lockfile、patch、CI 镜像和缓存是一条链。
3. 验证：干净安装、frozen lockfile、解析版本差异、类型检查、测试、构建、核心页面。
4. 发布：独立提交和灰度 CI；失败时回滚 packageManager 与 lockfile 整组文件。
5. 可观测性：记录安装耗时、缓存命中、依赖与 patch 漂移、构建产物差异。

**追问**

如何证明“依赖没升级”？如何设计失败回滚而不留下旧 node_modules 污染？

**关键取舍与风险**

- 原地迁移最短，但必须隔离依赖升级与业务代码。
- 缓存提速不能牺牲可信边界；不可信任务不能写入被可信任务复用的依赖缓存。
- patch hash 改变、peer 组合变化和 install script 是高风险点。

**落地改进**

统一 packageManager；CI 读取同一版本；frozen 安装；保存解析版本对比；迁移 PR 禁止混入格式化。

> 难度 高级 · 审校 已准入 · 首次 2026-08-20 · 主体系

## 可拖动 IM Launcher 的交互与性能闭环

**问题**

怎样把“支持拖动并记住位置”做成键盘、触摸、性能和恢复都可靠的组件？

**核心答案**

button 语义与 click/drag 阈值；Pointer Events + capture/cancel cleanup；ref+rAF+transform；viewport/safe-area clamp；结束时 versioned persistence；旋转/resize 恢复；单测、真实鼠标/触摸/键盘与 trace；flag/revert 回滚。

**边界与取舍**

先用已存在 hook 与浏览器 API，不引入通用拖拽库；只有复杂碰撞/多目标需求才升级。

**追问**

位置存左上像素、右下边距还是归一化比例，如何选择？

**风险**

原生 drag 冲突、丢 pointerup、每帧 storage、缩放后出屏、图标无可访问名。

**落地改进**

在现有 `use-launcher-position.test.ts` 补 cancel、损坏存储、resize clamp；组件测试覆盖键盘 click 与拖后不误触。

**状态**

**需求/边界**

button 语义、click/drag 阈值、Pointer capture/cancel、窗口 clamp、位置恢复和重置。

**状态/数据**

瞬时 ref、视觉 transform、最终 state；versioned storage 只写稳定值，损坏时回默认。

**性能/可观测**

rAF 合帧，避免每 move 存储；记录长任务/帧与设备/commit。

**测试/发布**

单测状态函数，组件测键盘与误触，真实触摸/鼠标/缩放验收；flag/revert 可回滚。
